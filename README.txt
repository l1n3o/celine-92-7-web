SDGs DI SEKITARKU - WEBSITE FILES

sdgs.html (SDGs Pilihan / SDG 12)
permasalahan.html
kerjasama.html
pancasila.html
ips.html
ttg.html (Tentang Saya)
dftr.html (Daftar Pustaka)
style.css

Install:
1. Extract this ZIP.
2. Copy all HTML files and style.css into your existing VS Code project folder.
3. Keep Header.png and 17sdgs.png in the same folder as index.html.
4. If your image filenames differ, update the src attributes in the HTML.
5. Open index.html with Live Server.

IPS, Tentang Saya, and Daftar Pustaka are editable templates.
The SDGs top-level tab is intentionally not a page link; hover over it to show its dropdown.
